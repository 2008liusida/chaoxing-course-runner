## 一分钟上手

### 第一次使用

| 步骤 | 你做什么 | 在哪里做 |
|---|---|---|
| 1 | 双击 **`Start.bat`** | 文件管理器 |
| 2 | 在弹出的浏览器窗口里**登录学习通** | 浏览器 |
| 3 | 打开课程的「学生学习页面」 | 浏览器 |
| 4 | 终端列出课节后按 **`y`** | 终端 |

登录与打开课程两步，**终端不需要你操作** ——
工具自己盯着页面状态，检测到就继续。

> 工具不保证跨次运行保留登录态。**每次运行请按提示正常登录**。
> 本工具不保存、不读取、不代填任何账号凭据。

### 日常使用

**双击 `Start.bat`**，然后跟着终端提示走。

日常用 `Start.bat` 即可。需要分步骤引导时（首次使用、排查问题），
可改用 `Run-Interactive.ps1`：

```
powershell -NoProfile -ExecutionPolicy Bypass -File Run-Interactive.ps1
```

两者用的是同一套逻辑与配置，跑起来后的行为完全一致。

### 运行时你会看到什么

控制台**只输出正文**，没有时间戳也没有级别标签，级别用颜色区分
（绿=完成、黄=警告、红=错误、灰=一般信息）。
播放阶段是一条就地刷新的进度条：

```
------ 课节 1222994220 完成（1/2）------
████████████████████░░░░░░░░  68%   12:34 / 18:20
```

进度条只在屏幕上刷新，**不写进日志文件** ——
否则一节课几百行会把"完成 / 跳过 / 失败原因"淹没。

日志文件里保留完整的时间戳与级别（`[2026-10-07 12:01:15] [INFO] ...`），
便于事后检索；播放里程碑只落盘、不上屏，避免打断进度条的就地刷新。

## 需要你回应的地方

**整个流程只需在终端按一次键。**

| 时机 | 你的操作 |
|---|---|
| 登录页出现时 | 在浏览器登录即可，**终端不用管** |
| 提示"打开目标课程"时 | 在浏览器打开课程页即可，**终端不用管** |
| 列出待处理课节后 | **输入 `y` 或回车** 开始 |

前两步工具会静默轮询页面状态，检测到就自动继续；
检测方式是"确认已到达目标状态"，因此**不会在你还没操作时就误判通过**。

等待不设催促提示，但设有长时间上限（4 小时）；
正常使用不会触及。

## 一条硬性规矩

**播放期间不要让浏览器窗口不可见。**

不要最小化、不要切到别的标签页、不要让它被完全遮住。

原因：Chromium 在页面处于 `hidden` 状态时**禁止加载和播放视频**。表现是视频时长一直读不到、进度原地不动。这是浏览器行为，不是工具缺陷。

工具每次进入新一节时会自动把窗口恢复并激活目标标签页，但你自己不去动它最稳。

## 常见问题

### 「页面不可见，视频可能无法加载」

工具没能把窗口恢复。请手动点一下那个浏览器窗口，让它显示出来。

### 某一节被判为"未完成，跳过"

常见原因：

- 该节要求 **100% 时长**（多数节只要 90%），而工具的重播次数用尽
- 该节的任务点不是视频，而是**作业 / 讨论 / 测验**，工具不处理这类
- 视频源加载失败

日志里会记下课节 id。建议手动打开那一节确认。

### 想停下来

按 `Ctrl+C`，或直接关掉终端窗口。**已经播完的课节不会重刷**，下次运行会自动跳过。

### 想只跑几节试试

```
Start.bat -MaxLessons 2
```

### 每次都要重新登录？

工具不保证跨次运行保留登录态，**每次运行请按提示登录**。
若你想清理浏览器数据，双击 `ClearCache.bat`：

- 直接双击：只清缓存，保留配置
- 加 `-All`：连 `browser-profile\` 一起删除

运行期间请勿清理 —— 脚本会先关闭工具浏览器，正在播的课会中断。

### 中途断网了

工具会在连续 3 节失败后**自动停止**并提示原因，不会长时间无响应。恢复网络后重新双击
`Start.bat` 即可续跑，已完成的课节不会重刷。

> 说明：切课阶段设有 4 分钟上限，主循环设有"连续 3 节失败即停"，
> 因此环境异常时工具会在几分钟内退出，而不是一直重试。

### 端口被占用（提示"调试端口连不上"）

编辑 `config.psd1`，把 `$DebugPort` 改成别的值（如 `9223`）。

### 一直停在选课提示，不往下走

工具在等你打开正确的页面。确认打开的是**课程的「学生学习页面」**：

- 正确：左边有课程目录、右边是视频播放器
- 错误：学习通「个人空间」首页（课程卡片列表那个页面）

工具只依据页面元素判断，不靠网址猜测，因此停在首页不会被误认成课程页。

### 想让它不要抢浏览器前台

默认会保持浏览器可见（这是视频能播放的前提）。若你希望提示阶段不抢焦点：

```
Start.bat -NoForeground
```

### 想换一个课程

直接重新跑 `Start.bat`，在浏览器里打开另一门课就行。工具以**你当前打开的页面**为准。

## 它不做什么

这些是刻意的边界，不是缺陷：

- **不代登录**：账号密码由你本人输入
- **不答题**：测验、作业、讨论都不碰
- **不加速**：平台会检测倍速，工具固定 1.0 倍速
- **不拖进度条**：会被平台判定为作弊
- **不批量操作多账号**
- **不做反检测**：不模拟鼠标轨迹、不伪造随机延迟、不改 UA、不绕心跳校验

最后一条需要展开说明，因为经常被问。

---

## 请读：平台能不能查出来

**没有工具能保证不被查出，本工具也不保证。** 这里如实说明它会留下什么特征，
你自己判断是否使用。

### 工具的实际行为（可自行验证）

| 项目 | 实际情况 |
|---|---|
| 播放倍速 | 1.0，每次轮询强制回正 |
| 进度条 | 从不拖拽 |
| 真实耗时 | 播放多久就耗时多久，不压缩时间 |
| 轮询节奏 | 每秒读取一次播放位置 |
| 浏览器 | 独立配置目录的真实 Edge 实例，非无头模式 |
| 反检测手段 | 无 |

### 服务端可能看到的信号（推断）

- **心跳时间线规整**：播放位置严格线性增长，1 秒一个采样点，中间没有暂停、回退、重播
- **会话时长连续**：不做干预时，工具会连续播放数小时不中断
- **零交互**：整个过程中没有鼠标移动、没有拖进度条、没有切换标签页
- **同一会话连续访问大量章节**：切课用的 `enc` 参数会随每次切课携带

这些特征叠加起来，"干净得不自然"。

### 未知的部分

- 平台是否真的在跑行为异常检测，还是只做基础时长校验
- 判定阈值在哪
- 判定后是清零时长、标记课程，还是上报学校

**这些作者也不知道。任何声称"这个不会被查"的说法都不可信。**

### 相对稳妥的用法

- **控制单次连续时长**：工具默认单次连续跑，建议中途停、隔天续跑
- **别追求"全自动刷完所有课"**：风险随连续时长与批量规模上升
- **重要课程别用**：如果这门课会影响毕业、评优，人工观看更稳妥

**时长是真的、倍速是 1.0，这是本工具唯一的"正当性"来源；但它无法伪装成真人在看。**

## 参数说明

在 `Start.bat` 后面加参数即可：

| 参数 | 作用 |
|---|---|
| `-MaxLessons 3` | 本次最多处理 3 节 |
| `-LessonIds 123,456` | 只处理指定课节 id |
| `-DebugPort 9223` | 换调试端口 |
| `-NoForeground` | 提示阶段不抢浏览器前台 |
| `-PollSeconds 5` | 进度轮询间隔（秒），默认 1 |

也可以直接调用 `Run-Interactive.ps1` 获得同样的参数与彩色输出。
