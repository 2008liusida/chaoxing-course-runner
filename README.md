# 超星学习通 · 自动连播工具

自动把学习通课程里**未完成的视频课节**一节一节播完，播完自动进入下一节，
直到目录里所有课节都变成"已通过"。

平台要求观看时长达标（常见 90% 或 100%），所以只能按 1 倍速真实播放，
一节课多久就得等多久。本工具解决的是**不用人守着点下一节**。

```
双击 Start.bat
  → 浏览器自动打开学习通登录页
  → 你登录（账号密码或 App 扫码）
  → 打开课程的「学生学习页面」
  → 终端列出待处理课节，按一次 y
  → 自动连播，可以走开了
```

日常只有一个入口：**双击 `Start.bat`**。
需要分步骤引导时（首次使用、排查问题），可改用
`powershell -ExecutionPolicy Bypass -File Run-Interactive.ps1`。

终端会逐步引导你，全程中文彩色提示。

**登录与打开课程这两步不需要你在终端操作** ——
工具会自己盯着页面状态，检测到就继续往下走。
只有最后列出待处理课节时，需要你按一次 `y` 确认开始。

之后就可以离开不管了。播放时会在同一行显示进度条：

```
████████████████████░░░░░░░░  68%   12:34 / 18:20
```

> 运行期间请勿最小化浏览器窗口或切到其它标签页 ——
> 页面不可见时浏览器会禁止加载视频（这是浏览器行为，不是工具缺陷）。

**完整流程、常见问题与参数说明见 [`docs/USAGE.md`](docs/USAGE.md)。**

## 特性

- 自动扫描目录，只处理未完成的课节；全部完成自动退出
- 断点续跑：中断后重跑会从剩下的未完成课节继续
- 无视频的课节（作业、讨论、测验）自动跳过并记录，不会卡死
- **单条进度条**：就地刷新，不逐行刷屏
- **控制台只输出正文**：不带时间戳与级别标签，级别用颜色区分，不刷屏
- 日志文件只记关键事件与分钟级里程碑，不被进度淹没
- **两种平台版本自动适配**：`legacy`（mooc1-2）与 `mooc2`（mooc1）
- 独立浏览器配置目录，不干扰你日常浏览器的标签页
- 启动时显示缓存占用，`ClearCache.bat` 一键清理
- **零第三方依赖**：只用 Windows 自带的 PowerShell，解压即用

## 不做的事

- **不改倍速**：平台会检测倍速，非 1 倍可能不计入时长
- **不拖拽进度条**：未完成任务点前平台本身就禁止拖拽
- **不代登录、不处理验证码**
- **不代答测验与作业**：那部分需要你本人完成
- **不做反检测**：不模拟鼠标轨迹、不伪造随机延迟、不改 UA、不绕心跳校验

## 安装与首次使用

1. 把整个目录拷到任意位置（例如 `D:\chaoxing-runner`）。

   > 不要拷贝 `browser-profile/` 与 `logs/`：
   > 前者是浏览器数据（跨机器无意义，还可能带凭据），后者只是历史日志。

2. 双击 **`Start.bat`**。
   会用一个独立配置目录启动浏览器（不影响你日常浏览器），
   并自动打开学习通登录页。

3. 在浏览器窗口里：
   - 登录学习通（账号密码或 App 扫码）
   - 打开你要处理的课程的「**学生学习页面**」
     （左侧有课程目录、右侧是视频的那个页面）

   这两步终端都不用管，工具检测到就自动继续。

4. 终端列出待处理课节后，按 `y` 开始自动连播。

5. 想中途停止：关掉黑窗口或按 `Ctrl+C`。已完成的课节不会重刷。

> **关于登录**：工具不保证跨次运行保留登录态，**每次运行都请按提示登录**。
> 这是刻意不做的工作 —— 登录记忆涉及凭据落盘，交由浏览器自身行为决定。

## 命令行参数

`Start.bat` 后面可直接跟参数，例如 `Start.bat -DryRun`。

| 参数 | 作用 |
|---|---|
| （无） | 自动处理所有未完成课节 |
| `-DryRun` | 只列出会处理哪些课节，不播放 |
| `-LaunchOnly` | 只启动浏览器并给出登录指引 |
| `-LessonIds 123,456` | 只处理指定课节 id |
| `-MaxLessons 3` | 本次最多处理 3 节 |
| `-DebugPort 9223` | 换调试端口（默认 9222，被占用时用） |
| `-NoForeground` | 不把浏览器抢到前台（见下方说明） |
| `-StopBrowserWhenDone` | 跑完后关闭工具专用浏览器 |
| `-NoLaunch` | 不自动启动浏览器（要求端口上已有实例） |

课节 id 怎么找：先跑 `Start.bat -DryRun`，日志里会列出每个待处理课节的 id。

> **关于 `-NoForeground`**：默认会保持浏览器前台，因为超星的完成条件
> 写明"观看时不可离开或将页面最小化"。如果你需要在跑的同时用电脑，
> 可以用这个开关关掉，但要自己保证窗口可见、不被最小化。

## 配置

只改 `config.psd1`，保存后下次运行生效。常用项：

| 配置 | 默认 | 说明 |
|---|---|---|
| `$Browser` | `msedge` | 用哪个浏览器，可填 `chrome` |
| `$DebugPort` | `9222` | 调试端口 |
| `$ProfileDir` | 空 | 空 = 用本目录下 `browser-profile` |
| `$LessonIds` | 空 | 空 = 自动扫描所有未完成课节 |
| `$MaxLessons` | `50` | 本次最多处理几节 |
| `$MaxReplayPerLesson` | `1` | 播完未登记时允许从头重播几次 |
| `$MaxWaitMinutesPerLesson` | `40` | 单节最长等待，超过则跳过 |
| `$PlaybackRate` | `1.0` | 播放速率，**不建议改** |
| `$PollSeconds` | `1` | 进度轮询间隔（秒），1 = 每秒刷新进度条 |
| `$KeepForeground` | `$true` | 是否保持浏览器前台 |
| `$SwitchMode` | `auto` | 切课方式，一般不用改 |

浏览器数据清理：双击 `ClearCache.bat`（也可加 `-All` 连配置目录一起删）。
运行期间请勿清理 —— 脚本会先关闭工具浏览器，正在播的课会中断。

键名写错会被忽略（不会导致启动失败），但值非法（如 `SwitchMode` 写错）
会在启动时报错，便于早发现。

## 工作原理（简述）

用 Windows 自带的 PowerShell 通过**浏览器调试协议（CDP）**直连浏览器，
读真实 DOM、控制真实 `<video>`。

关键判据（全部读 id/class，**不依赖界面文字** ——
因为课节标题被反爬字体处理过，`innerText` 是乱码）。

工具支持学习通的两个并行版本，运行时自动识别（见 `lib/Selectors.psd1`）：

| 用途 | 版本 A：`legacy` | 版本 B：`mooc2` |
|---|---|---|
| 主机 | `mooc1-2.chaoxing.com` | `mooc1.chaoxing.com`（URL 带 `mooc2=1`） |
| 课节节点 | `h5[id^=cur]` | `div.posCatalog_select` |
| 未完成判据 | `span.roundpoint` 的 class 含 `orange` | `input.jobUnfinishCount` > 0 |
| 当前课节 | `<input id="curChapterId">` | `div.posCatalog_active` 的 id 去 `cur` 前缀 |
| 目录位置 | 顶层文档 | iframe 内 |

两版共用：三层 iframe 结构
（`studentstudy → knowledge/cards → ananas/modules/video`）、
任务点判据 `.ans-job-finished`、切课函数 `getTeacherAjax`。

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) —— 分层、设计取舍、PowerShell 5.1 兼容坑

## 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 一直停在"登录页开好了，去登陆吧~" | 登录还没完成。工具在静默等待，**不会催你也不会误判**；登录成功会自动继续 |
| 一直停在选课提示 | 已登录但还没进课程页。点进具体课程，进入「学生学习页面」即可 |
| 提示"读不到课程目录（0 个课节）" | 页面没加载完，或平台改版导致选择器失效。先确认页面正常，必要时刷新；仍不行见 `docs/PLATFORM-CONTRACT.md` |
| 一直"时长未就绪，尝试播放" | 视频没加载出来。**先检查浏览器窗口是否可见/是否被最小化**；工具也会自动刷新一次，仍不行就跳过该节 |
| 播完但目录没变 | 该节可能要求 100% 时长或另有任务点；工具会重播一次，仍不行则记录，建议手动看一眼 |
| 连续 3 节失败后停止 | 环境异常（断网 / 登录过期 / 浏览器被关）。恢复后重跑即可，已完成的不会重刷 |
| 弹出验证码 | 工具会停住，需你处理后重跑 |
| 端口被占用 | 改 `config.psd1` 里的 `$DebugPort`，或用 `-DebugPort 9223` |
| 想清空浏览器数据 | 双击 `ClearCache.bat`；要连配置目录一起删就加 `-All` |
| 中文显示成乱码 | 脚本必须带 UTF-8 BOM（仓库内已处理）；确认没有被编辑器改成无 BOM |

排障先看 `logs/run.log`：里面有每节结果、切课方式与失败原因，
异常时还会写出**实际执行的 JS**，可直接贴到浏览器控制台验证。

## 离线自测

不接触真实课程也能验证链路是否正常。夹具复刻了真实页面结构与 URL 路径
（`knowledge/cards.html` → `ananas/modules/video/index.html`）：

```powershell
# 1) 语法/导出/配置校验（不需要浏览器）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\module-smoke.ps1

# 2) JSON 数组解析在 5.1/7.x 的行为
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\check-jsonarray.ps1

# 3) 选择器与夹具结构是否对齐（需要浏览器已开调试端口）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\check-fixture.ps1

# 4) 端到端：识别 -> 播放 -> 登记 -> 下一节（自动起本地服务）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\run-fixture.ps1
```

## 使用须知

- 请只用于**你自己已选课程**的常规观看，不要用于他人账号或批量操作。
- 工具按平台规则播放（1 倍速、不拖拽），但**是否计入成绩由平台判定**，
  本项目不对判定结果作保证。
- 长时间运行时请确认电脑不会睡眠：
  `powercfg /change standby-timeout-ac 0`
- 请留意使用节奏。真人观看会有停顿与中断，
  长时间零间隔连续播放更容易被平台的风控注意到。
- 本工具**不保存登录凭据**，也不保证跨次运行保留登录态；
  每次运行请在浏览器里正常登录，账号安全由平台与你本人负责。
